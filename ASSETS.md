ASSETS.md — Yalçın Pastaneleri

1. Core Principle

Never generate, draw or invent visual assets.

All visual elements must come from authentic, existing sources on the internet.

No AI-generated images, illustrations, icons, logos or product photography.

2. Asset Sources

Brand & Photography

* Instagram: https://instagram.com/yalcinpastaneleri
* Official menu: https://qrmenu.yalcinpastaneleri.com
* Official website and verified business profiles.
* Google Maps business photographs.
* Actual product and branch photographs.

Prioritize official Yalçın Pastaneleri content. Verify asset authenticity and usage permission before publishing.

3. Icons

Never manually draw icons using CSS, SVG paths, Canvas or AI.

Use established, professionally designed icon libraries:

* Lucide Icons
* Phosphor Icons
* Heroicons
* Material Symbols

Choose one primary icon family and maintain consistency across web and mobile.

Never use emojis instead of icons.

4. Product Photography

* Every product must use its actual photograph.
* Never substitute images from other bakeries.
* Never generate artificial product images.
* Preserve original colors, proportions and textures.
* Use high-resolution originals whenever available.
* Never stretch, distort or heavily filter photographs.

If an authentic image is unavailable, use a clean text-based placeholder until the correct asset is obtained.

5. Asset Management

Download approved assets into the project.

assets/
├── brand/
├── products/
├── branches/
├── banners/
└── icons/

Use descriptive, consistent filenames.

Optimize images using WebP/AVIF where supported.

Never hotlink third-party image URLs in production without explicit authorization.

6. Strict Requirements

* Search official sources before adding any asset.
* Never fabricate missing assets.
* Never use generic stock bakery photography.
* Never recreate the company’s logo.
* Never introduce unrelated visual styles.
* Do not use copyrighted third-party content without permission.
* Respect asset licenses and attribution requirements.
* Use assets that match the actual business and product.

7. Final Rule

Search → Verify → Obtain Permission → Download → Optimize → Implement.

Every visual element must be authentic, professionally designed, legally usable and consistent with design.md.

If a suitable asset cannot be found, report the missing asset instead of generating a replacement.
